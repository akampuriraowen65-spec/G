# OwiTok
Purple short-video web app for GitHub Pages.

## Files
- index.html — app structure
- style.css — purple TikTok-style interface
- script.js — feed, likes, comments, follow, profile, settings, camera/gallery, swipe navigation
- logo.svg — OwiTok logo
- manifest.json — installable web-app information
- service-worker.js — offline app shell
- .github/workflows/deploy.yml — GitHub Pages deployment

## GitHub Pages
Keep the workflow at `.github/workflows/deploy.yml`. In repository Settings > Pages, use GitHub Actions as the source.
